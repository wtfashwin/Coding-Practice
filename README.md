# Coding Practice

Python solutions and notes for practicing algorithms, data structures, and interview problems.

## Contents

| Folder | Focus |
| --- | --- |
| `Arrays/` | Array and stock-profit exercises |
| `Strings/` | Palindromes, subsequences, prefixes, and string conversion |
| `Patterns/` | Console pattern printing |
| `Hackerrank Interview Preparation Kit 1 week/` | Day-by-day HackerRank exercises |
| `Leetcode/` | Python solutions and Markdown explanations of approaches |

## Use an exercise

Use Python 3. Files have different entry points: some are interactive scripts, while others define a judge-style `Solution` class or a function without a command-line runner. Read the selected file's problem statement and input format first.

For a small interactive example, run:

```bash
python "Patterns/squarestar.py"
```

Enter a side length to print a filled square of stars.

For a HackerRank example:

```bash
python "Hackerrank Interview Preparation Kit 1 week/Day 1/plusminus.py"
```

Enter the array length on the first line and the space-separated integers on the second. The script prints the fractions of positive, negative, and zero values.

LeetCode files such as `Arrays/Best Time to Buy and Sell Stocks.py` define a `Solution` method to call from a judge or your own test harness. Markdown files such as [Coin Change](Leetcode/coin-change.md) explain multiple approaches and link to the original problem.
